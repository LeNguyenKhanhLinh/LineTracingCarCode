# Line tracing car#
The Line Tracing Car is a small autonomous vehicle designed to follow a track by detecting the contrast between a line and the surrounding surface.
The car uses sensors to detect the position of the line and adjusts the speed and direction of its motors to stay on the track.
This project aims to explore embedded systems, sensor integration, and real-time motor control.
# Hardware components
- Micro-Controller: Arudino
- Line Sensor: 4 light diodes
- Other components: Not remember
